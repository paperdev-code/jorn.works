# Jorn.works

My personal page, it's a work-in-progress.

Uses a `<pre>` tag with WebAssembly to render some interative elements using [dots](https://github.com/paperdev-code/zig-dots).

View [here](https://jorn.works).

## Build

```sh
zig build

# and host locally

zig build serve
```
